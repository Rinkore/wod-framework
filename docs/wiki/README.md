## 一分钟概览

- **你要做的事**：创建英雄 → 派遣进迷宫（真实时间倒计时）→ 读战报 → 训练技能/换装备 → 挑战更深的迷宫。
- **主要成长资源**：**金币**（技能训练、交易、删号）与 **EP**（升级、解锁技能树节点）；彩票另有遗产碎片与训练手记，手记只增加可用 EP，不提升等级。
- **装备**：迷宫掉落、市场交易、背包出售；没有炼药消耗品、锻造材料与装备强化。另有彩票库存奖券、遗产碎片和训练手记，见[彩票](lottery.md)。
- **决斗不给 EP**：竞技场只影响积分、声望与赛季排名——变强请下迷宫。
- **市场成交收 5% 手续费**，拍卖行同率；公会仓库是队伍共享的装备柜。
- **战败即死**：被击败时倒地的角色永久死亡；撤离条件能在危局中救回所有人。死亡名册无容量软锁，不因人数多删死者；可免费归档墓碑、装备回包。旧赦免/赎回券仍可用，新彩票不再发复活券。
- **迷宫 3–4 人组队准入**：派遣与组队出发都需要 3–4 名英雄。

## 名词表

| 名词 | 含义 |
| --- | --- |
| EP（经验点） | 升级与解锁技能树节点的资源；`xp` 为剩余可用量，`ep_earned` 为累计值 |
| 过往 | 英雄的出身（种族），决定初始被动、特质技能与迷宫亲和 |
| 武器路径 | 8 种武器各有一条技能树（音叉形，11 个节点） |
| 站位 | 前排 / 游走 / 后排；游走可绕过敌方前排攻击后排 |
| 亲和 | 过往与迷宫标签匹配后的福利（额外搜刮、快速通路、野外休整） |
| 深层 | 进阶副本系列的第 2–5 层，需逐层打通 boss 解锁 |
| 撤离条件 | 战前配置：任意角色达成 → 全员成功撤离（保留掉落、无人死亡） |
| 死亡名册 | 死亡角色列表，无容量软锁，不阻止创建或派遣、不因人数多删除死者；可免费归档为墓碑，装备回背包 |
| 死亡赦免券 | 旧券兼容：复活一名死亡名册中的角色；新彩票不再发放 |
| 死亡赎回券 | 旧券兼容：从墓碑恢复一名角色，归档装备仍在背包；新彩票不再发放 |
| 库存奖券 | 掉落时无号码、不自动参彩；玩家分批投入当前日池，每批最多 10000 张、总量不限，未投入跨日保留 |
| 每日日池 | 每张投入券生成 6 个不重复号码（00–30），不可撤销；服务器当地每天 00:00 开奖，奖励自动入账 |
| 遗产碎片 / 训练手记 | 10 碎片换 1 手记；为累计 EP ≤5000、存活且不忙的英雄增加 250 可用 EP，不加累计 EP 或等级，每英雄最多 3 次 |
