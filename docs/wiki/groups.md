# 组队玩法

## 队伍基础

- 每个账号同一时间只能在一个队伍里；队伍最多 **4 名英雄**（可以全由一个账号的英雄填满）。
- 队长建队后获得 **6 位邀请码**（字母数字，去除易混淆字符）。

## 可见性与加入

| 模式 | 谁能直接加入 |
| --- | --- |
| 公开 | 任何人 |
| 仅邀请 | 只有凭邀请码 |
| 好友 | 队长的好友 |
| 公会 | 队长同公会成员 |
| 公会+好友 | 两者皆可 |

公开/好友/公会模式会出现在「可加入队伍」列表；仅邀请队伍只能靠邀请码。

## 流程：通知 → 准备 → 出发

1. 队长在队伍页**选择迷宫与路线**并发起通知（会清空所有人的响应状态）。
2. 队员点**准备**（重伤英雄会被拒绝，需先治疗或移出队伍）或**拒绝**（留在队伍但不参加）。
3. 全员准备后队长点**出发**，创建远征：所有 staged 英雄一起进迷宫（**3–4 名**），倒计时同单人远征。死亡名册无容量软锁，死者人数不影响出发。
4. 结算后队伍**保留**，回到待命状态，队长可以直接通知下一场。

队长改迷宫、取消通知随时可以；远征进行中不能解散队伍、成员不能退出、英雄不能被移出。

## 英雄管理

- 成员各自把自己的英雄加入队伍并选站位/预设/撤离条件；队长可以代为调整队员英雄的预设选择。
- 只有英雄的主人（或队长移除）能把它移出队伍。

## 奖励分配

结算时按**参战英雄的主人**（去重后的账号）分配：

- **金币**：总金币平分，余数给第一位。
- **装备**：按人头轮转（第 1 件给第 1 人，第 2 件给第 2 人……循环）。
- **EP**：按英雄结算，各拿各的；被击倒的英雄半 EP。
- **彩票库存券**：满足[彩票掉落](lottery.md#掉落)条件时，每个参战账号各掷骰一次，同账号多名英雄不增加次数；掉券后由玩家自行投入日池。
- 战报里会显示每个人的份额与掉券提示。

没有 staged 英雄的成员不参与分配。
