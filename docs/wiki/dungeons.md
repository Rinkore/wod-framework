# 迷宫与远征

## 迷宫结构

每座迷宫是一张固定布局的房间图：入口、若干战斗房、宝箱房、一个 boss 房，由边连接。

| 房间 | 行为 |
| --- | --- |
| 入口 | 不计时、不遭遇 |
| 战斗 | 与怪物编成战斗；胜利后获得怪物金币、掉落与该房的搜刮表 |
| 宝箱 | 无战斗，清空即拿掉落表与金币 |
| 首领 | 战斗房；击杀并全清所选路径 = 打通 |

路线规划：从入口出发沿相邻房间前进、不重复；可以选系统最短通路，也可以自选路径（比如绕进宝箱房）。路线会按玩家记忆保存，下次派遣默认沿用。

## 队伍准入

- 派遣与组队出发都需要 **3–4 名英雄**（下限 3、上限 4）。

## 等级准入

- 判定只看**队伍平均等级**（向下取整）：任意所选房间的怪物等级不得超过 **平均等级 + 5**。
- 战力只是怪物强度参考，不设玩家战力门槛。
- 越深的层怪物等级越高，掉落与金币也越高——升级永远是第一生产力。

## 深层解锁（进阶系列）

- 3 条进阶系列（断炉 / 档案厅 / 空庭）各有基础层 + 深层 I–IV。
- 打通某一层（全清路径并击杀 boss）解锁**下一层**，逐层推进。
- **组队时要求全员解锁**：队长选深层出发前，每个参战英雄的主人都必须已打通上一层；报错会点名谁没解锁。

## 过往亲和

队伍成员的过往与迷宫标签匹配时获得福利：

| 福利 | 效果 |
| --- | --- |
| 熟路搜刮 | 每个清空的战斗房额外掷一次搜刮表 |
| 快速通路 | 迷宫临时追加若干近路，可缩短路线 |
| 野外休整 | 房间之间额外恢复生命与法力 |

亲和是定性的福利，不加数值。

## 派遣与结算

- 派遣后战斗结果按种子在服务端预计算，倒计时只是真实时间的流逝，结算时不会重掷。
- **胜利（全清所选路径）**：保留全部掉落 + 金币 + EP +（若走到 boss）通关奖励与声望，**无人死亡**。
- **成功撤离**：撤离条件触发时全员撤出——保留已得掉落与全额 EP，无人死亡，无通关奖励。
- **提前收队**：手动召回且路径全清——保留已得掉落，但没有通关奖励。
- **战败**：在某房间打输——**丢掉本局全部物品掉落**，所有倒地的角色**永久死亡**。谨慎规划路线，善用撤离条件。
- 组队远征的金币平分、装备按人头轮转分配，见[组队玩法](groups.md)。

## 掉落

- 掉落表在每次掷骰时按权重抽取：先判概率，再按权重选模板。
- 装备掉落时**即时掷词缀**：稀有以上品质带 1–3 条词缀（修正词缀掷点，特效词缀固定）。
- 品质决定词缀数与出售价值：普通 0 条、精良 1 条、稀有 2 条、史诗 3 条。

## 彩票掉落

- 迷宫胜利或成功撤离且实际清理过房间时，按**实际清理房间的最高怪物等级**掷掉落概率：`min(0.5, 0.06 + 最高怪物等级 × 0.01)`，不计尚未清理的高等级房间，掉率不下调。
- 每次远征按参战账号各结算一次，同账号多英雄不重复掷骰；战报会提示掉券。周出票量仅统计，**无软上限、不因出票量减少掉落**。
- 掉落为**无号码的库存券**，不会自动参与开奖，未投入可跨日保留。玩家分批投入当前日池，每批最多 10000 张、投入总量不限；每张投入时随机生成 6 个不重复号码（00–30），不可撤销。
- 服务器当地每天 00:00 开奖并自动发奖，详见[彩票](lottery.md)。
