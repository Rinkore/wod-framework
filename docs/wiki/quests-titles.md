# 任务与称号

## 任务

任务分为几类（主线 / 支线 / 挑战等），目标类型包括：

| 目标 | 进度方式 |
| --- | --- |
| 打通某迷宫 | 全清所选路径并击杀 boss |
| 赢一场远征 | 远征胜利 |
| 击败 N 只怪物 | 累计击杀数 |
| 获得 N 声望 | 累计声望获取 |
| 赢 N 场决斗 | 竞技场胜利 |

- 任务按**前置任务**链式解锁：前置全部领取后才变为进行中。
- 进度按账号累计，不区分英雄。
- 完成后手动**领取奖励**；每项任务只能领一次（重复请求无效）。奖励可能是金币、EP、声望或直接授予称号。
- 领取 EP 奖励时选择一名英雄接收（默认给最强英雄）。

## 声望

声望来源：迷宫通关奖励、任务奖励、决斗胜利（+1/场）、赛季奖励。

声望按**英雄**累计，同一账号不同英雄各自计算。

## 称号

- 达到声望阈值自动解锁对应称号（历史最高声望不回退）。
- 部分称号由任务直接授予。
- 英雄详情页可设置**展示中的称号**（或选择不展示）；未手动选择时自动佩戴已解锁的最高阈值称号。
- 称号纯展示，无属性加成。
