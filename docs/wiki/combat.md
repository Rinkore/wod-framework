# 战斗系统

迷宫战斗与竞技场决斗共用同一套引擎：种子化、回合制、最多 25 回合（决斗 20 回合）。超时会明确标记为撤退：保留已取得的远征战利品，不按普通战败处理。

## 战斗阶段

每回合按顺序执行三个阶段，技能可声明自己能出现在哪些阶段：

| 阶段 | 时机 | 频率 |
| --- | --- | --- |
| 回合前（pre） | 主行动之前 | 每回合一次 |
| 先攻（initiative） | 只用于确定主回合的出手顺序 | 不单独行动 |
| 主回合（main） | 每名单位执行一次主要行动 | 每次 action 一击 |

英雄和怪物每回合都只有一次主要行动；先攻不会跨阈值增加整回合行动，也不会额外制造一次攻击。冷却中的技能自动跳过，法力不足时智能选择其他可用技能或普攻。

## 站位

| 站位 | 效果 |
| --- | --- |
| 前排 | 正常交战 |
| 游走 | 近战可以**绕过敌方前排**直接攻击后排；在下次行动前处于暴露状态 |
| 后排 | 远程武器（弓/法杖/经卷/乐器）默认后排，近战从前排开始 |

## 命中、暴击与伤害

- **命中评分 vs 闪避评分**：决定一次攻击是否命中；未命中不产生伤害。防御端的「未能命中」与「闪避」是分开结算的两种失败。
- **暴击**：暴击率（百分点）判定，暴击伤害倍率由面板提供。
- **伤害类型**：打击 / 斩击 / 穿刺 + 元素伤害；护甲对物理伤害减伤（护甲 / (护甲 + 系数 × 伤害)），抗性对元素/混沌伤害按双通道结算。
- **修正词条**：装备词缀与技能提供增减益（受伤减免、命中率、暴击率等），战斗中动态生效。

## 异常状态

攻击与特效可施加异常：出血、中毒、灼烧、冻结、麻痹、眩晕等。持续伤害/控制按回合在**回合开始时**结算，战报会标注施加者与来源技能。元素/混沌抗性也会降低灼伤和中毒的持续伤害；中毒与伤口最多 3 层、最多持续 6 回合，避免长战无限叠加。

## 目标优先级

每个英雄（或每层覆盖）可设置主回合目标选择：

- 最近目标（默认）
- 最低生命
- 施法者
- 最强目标

## 战斗预设

每个英雄最多 **5 套预设**，保存：

- 站位与目标优先级
- 回合前辅助效果与主回合技能顺序（先攻只改变主回合排序）
- 按层覆盖（1–10 层各自独立的目标优先级与技能顺序）
- 绑定迷宫（派遣该迷宫时自动套用）

派遣时可直接选预设；未指定则优先使用绑定该迷宫的预设，否则用默认预设。临时修改只在本次远征生效，不写回预设。

## 撤离条件

战前配置（预设或派遣时临时设置）可以为每名英雄指定一条**撤离条件**：

| 触发方式 | 含义 |
| --- | --- |
| 自身生命低于 X% | 战斗结束后生命比例低于阈值 |
| 队伍倒地达到 N 人 | 已有 N 名队友（含自己）被击倒 |
| 推进到第 N 房后 | 已清空 N 个房间 |

**任意角色的撤离条件在某个房间清空后达成时，全队立即成功撤离**：保留已得掉落与 EP，全员存活（哪怕已有人倒下也会被救回），但没有通关奖励。撤离是永久死亡制度下最重要的保命手段。
