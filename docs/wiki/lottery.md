# 彩票

迷宫随机掉落**无号码的库存奖券**，玩家自行投入当前日池；服务器当地每天 **00:00** 开奖，奖励自动入账。新彩票奖励为遗产碎片、训练手记与收藏称号，**不再发放复活券**。

## 掉落

| 因素 | 规则 |
| --- | --- |
| 掉落时机 | 迷宫**胜利或成功撤离**，且本次实际清理过房间，结算时掷骰 |
| 掉落概率 | `min(0.5, 0.06 + 实际清理房间最高怪物等级 × 0.01)`；只看实际清理的房间，不看尚未到达的高等级房间 |
| 结算单位 | 每次远征按**参战账号**各结算一次，同账号带多名英雄不增加次数；掉券会在战报提示 |
| 库存奖券 | 掉落时**没有号码、不绑定期次、不自动参与开奖**；未投入的奖券跨日保留 |
| 周出票量 | 统计最近七天出票量，仅供查看；**无软上限，不因出票量降低掉率** |

## 投入当前日池

- 玩家自行选择库存中要投入的任意张数，可分批投入**当前日池**。
- 每批投入 **1–10000 张**，可继续分批投入，**投入总量不限**。
- 每张奖券在投入时随机生成 **6 个互不重复的号码**，范围 **00–30**，按升序显示；号码位数不再随副本等级变化。
- 投入后不可撤销，也不能移到其他日池；未投入的库存不受当日开奖影响。

## 开奖与自动入账

- 日池按**服务器当地日历日**划分，每天 **00:00** 为上一日池开奖，并开启新日池，无需玩家在线。
- 开奖抽出 **6 个号码**（00–30，不重复，升序公布）。
- **只看数字、不看顺序**：每张已投入奖券与开奖号码的交集大小即命中数。
- 已投入奖券的奖励在开奖时**自动入账**，无需手动兑奖；重复查看结果不会重复发奖。

## 奖励表

以下为**每张已投入奖券**的奖励：

| 命中数 | 遗产碎片 | 训练手记 | 收藏称号 |
| --- | --- | --- | --- |
| 0 或 1 个 | 1 | — | — |
| 2 个 | 3 | — | — |
| 3 个 | 10 | — | — |
| 4 个 | 40 | 1 | — |
| 5 个 | 200 | 3 | 拾光者 |
| 6 个 | 1000 | 3 | 雨幕见证者 |

同账号重复获得「拾光者」时，额外折为 **40 碎片**；重复获得「雨幕见证者」时，额外折为 **200 碎片**。表中的基础碎片与手记照常发放。

## 训练手记

- **10 枚遗产碎片兑换 1 本训练手记**。
- 手记只能用于本账号**累计 EP ≤5000、存活且不忙**的英雄。
- 每本增加 **250 可用 EP**，**不增加累计 EP，也不提升等级**。
- 每名英雄最多使用 **3 次**；使用失败不消耗手记或次数。

## 历史奖券与复活券兼容

- 旧版尚未开奖的 **pending** 票迁为库存券，清除旧号码与期次；需由玩家主动投入当前日池，才参与新开奖。
- 旧版已开奖的 **drawn** 票保留原结果与旧奖励，可随时**手动领取一次**，不按新奖励表重算：

| 旧票命中数 | 保留的旧奖励 |
| --- | --- |
| 0–2 个 | 50 金币 |
| 3 个 | 死亡赦免券 ×1 |
| 4 个 | 死亡赦免券 ×3 |
| 5 个 | 死亡赎回券 ×1 |
| 6 个 | 死亡赎回券 ×5 |

已有的旧复活券仍可在英雄页使用：

- **死亡赦免券**：复活死亡名册中的一名角色，保留等级、技能与身上装备。
- **死亡赎回券**：从墓碑恢复一名角色，保留等级与技能；已归档退回背包的装备仍在背包，需要重新装备。

死亡名册无容量软锁，不因死者数量多而删除角色；玩家可将死亡角色免费归档为墓碑，装备回背包。详见[英雄与成长](heroes-and-skills.md#永久死亡与死亡名册)。
