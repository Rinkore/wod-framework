# 经济系统

## 金币来源

| 途径 | 说明 |
| --- | --- |
| 迷宫怪物与房间金币 | 每个清空的房间按区间掷骰 |
| 通关奖励 | 打通迷宫的额外金币区间 |
| 出售装备 | 商人价 = 价值 × (0.45 + 品质系数 0.02×档位)，普通约四六折、史诗约五五折 |
| 任务奖励 | 部分任务发金币 |
| 赛季排名奖励 | 每个赛季结算时按排名发放 |
| 新账号 | 起始资金 100 |

## 金币去向

| 途径 | 说明 |
| --- | --- |
| 技能训练 | 金币 = 该次 EP 费用 × 0.9 |
| 治疗重伤 | 20 + 5 × 英雄等级 |
| 市场购买 | 全额支付给卖家（卖家侧收 5% 手续费） |
| 拍卖出价 / 一口价 | 托管扣款，被超价自动退回 |
| 公会金库 | 存入/取出（取出仅会长） |
| 删除英雄 / 死亡归档 | 主动删除存活角色需 **100 金币**（输入英雄全名二次确认）；死亡角色免费归档为墓碑，装备回背包，死亡名册无容量软锁 |

## 背包出售

- 背包页对未装备的装备可直接出售，出售后无法撤回。
- 价格按品质固定公式，不议价。

## 市场（玩家挂单）

- 只能上架**未装备的装备**，价格 1–1,000,000 整数。
- 挂单保留 **7 天**，到期自动退回背包；下架随时可做、免费。
- 成交后**买家付全价，卖家实收 95%**（5% 手续费，与拍卖行一致）；上架表单会实时显示预计实收。
- 不能购买自己的挂单。

## 拍卖行

- 起拍价 1–1,000,000；可选一口价（必须高于起拍价）与时长 1–72 小时（默认 24）。
- **出价即托管**：出价时立刻扣款；被别人超价自动全额退回；自己加价时先退旧价再扣新价。
- 结束时：有出价 → 最高价成交，卖家收 到手价（扣 5% 手续费），买家收物品；无出价 → 物品退回卖家。
- 有出价后卖家不能取消拍卖。

## 公会仓库

- **金库**：任何成员可存金币；只有**会长**能取出。
- **仓库**：成员存入未装备的装备；只有**会长**能取出。
- 解散公会时，金库与仓库全部回到会长账号。

## 反刷保障（面向玩家的说明）

- 所有金额输入服务端强制为正整数，不存在负数存取。
- 新彩票每日开奖自动入账遗产碎片、训练手记与收藏称号，不发金币或复活券；命中 0/1 个也得 1 碎片。**10 碎片可换 1 手记**，每本为累计 EP ≤5000、存活且不忙的英雄增加 250 可用 EP，不增加累计 EP 或等级，每英雄最多 3 次，失败不消耗。仅旧版已开奖票保留旧奖励并可手领一次（旧票 0–2 命中仍为 50 金币），详见[彩票](lottery.md)。
- 任务、赛季奖励领取均有一次性标记，重复请求无效。
- 远征结算按状态机幂等处理，重复触发不会双发奖励。
