# 竞技场

竞技场提供两套兼容的 PvP 规则：当前推荐的**竞技场队伍**是每个账号独立维护的一支 4v4 队伍；旧版 1v1 决斗接口仍保留给旧客户端。队伍竞技场的路由位于 `/api/colosseum/team/*`，页面使用队伍后会优先显示队伍榜、队伍历史和队伍赛季。

## 4v4 独立队伍

- 每个账号最多一支竞技场队伍；队伍必须恰好包含 **4 名不同英雄**，每名英雄都要指定 `front`、`flank` 或 `back` 站位。
- 队伍是账号的独立竞技实体：队伍有自己的战力、积分、胜负、幻影快照和历史，不与迷宫组队、公会或其他账号的英雄编组共享。
- 保存或修改队伍时，4 名英雄必须属于当前账号、未在远征中且未永久死亡。发起挑战时，自己的 4 名英雄仍须可用；竞技场战斗不会造成重伤或死亡。
- 一名英雄不能在队伍配置中重复；英雄更换后要重新保存队伍。队伍创建时积分为 1000，战绩为 0–0。

### 幻影（防守快照）

- 对手不是实时读取其英雄状态，而是使用该队最近保存的**防守幻影**：4 名英雄的战斗快照（等级、技能、装备、站位等）和快照时间。
- 首次保存队伍时生成幻影；以后编辑阵容只更新当前队伍和战力，**不会**刷新幻影。这样离线玩家仍可被挑战，且防守方不会因临时换装而改变已公开的防守阵容。
- 主动挑战获胜后，攻击方才用本次可用阵容更新自己的幻影；战败不会刷新幻影。对手列表展示的是幻影成员和幻影时间。
- 战斗由服务端立即用同一战斗引擎结算并保存完整战报；防守方不需要在线。

## 挑战限制与反刷分

- 每个账号每天最多主动发起 **5 次**队伍挑战（按服务器本地日统计）。
- 同一攻防方向的两支队伍之间有 **48 小时冷却**；冷却只限制相同的攻击方 → 防守方组合。
- 默认只能挑战积分高于自己的队伍；若双方队伍战力差小于 **1%**，允许作为近似同战力例外挑战。
- 同一防守方队伍在服务器本地日内被击败后，后续针对该队伍的胜利收益会衰减：当天第一次击败该防守队伍的收益为理论值的 100%，第二次为 25%，再后续为 0；防守方对应扣分使用同一实际转移值。
- Elo 期望值使用 K=24；实际转移按反刷分衰减，并且是零和转移且积分最低为 0。战报同时保留理论变化与实际变化，便于审计。
- 这些规则共同限制重复喂分：每日次数、方向冷却、只能向上挑战、同日防守胜利收益递减。HTTP API 返回 `challenge` 中的 `dailyUsed`、`dailyLimit`、`cooldownUntil`、`powerException` 和 `defenderMultiplier`，客户端应直接展示服务端判定。

## 积分、战绩与排行榜

- 队伍初始积分为 1000；胜负更新队伍积分与总胜/败。积分和总战绩保存在队伍记录中，不因登录或编辑阵容而重置。
- `/api/colosseum/team/leaderboard` 返回有过至少一场比赛的队伍，按积分、胜场、更新时间排序；榜单成员名来自队伍防守幻影。
- `/api/colosseum/team/history` 返回当前账号作为攻击方或防守方参与的最近 20 场队伍战报。

## 赛季与持久化

- 赛季默认 **14 天**，由服务端按时间懒创建和滚动；测试可用 `WOD_SEASON_DAYS` 调整（最短仍为 1 分钟）。赛季过期后，下一次竞技场请求会结束上一赛季并创建新赛季。
- 队伍的长期积分、总胜负和幻影**跨赛季保留**。赛季表为每个赛季、每支队伍保存独立排名快照：首次参赛时从队伍当前长期积分初始化，之后记录该赛季的胜负和积分变化；新赛季不会把队伍长期积分重置为 1000。
- 赛季排名按赛季积分 → 胜场数 → 更新时间排序。只有赛季内至少比赛一场的队伍进入奖励结算。
- 赛季奖励沿用金币、EP、声望梯度：第 1 名 500/500/10，第 2–3 名 300/300/6，第 4–10 名 150/150/3，第 11–25 名 80/80/1，其余参赛队伍 30/30/0。队伍奖励记录该赛季参赛时的 4 名英雄；领取时金币发给账号，EP 与声望按结算快照在仍属于该账号的队员间平均分配，余数按快照顺序分配。
- 奖励可跨多个已结束赛季累积领取；领取在事务中标记，重复领取不会再次发放。队伍赛季页面为 `/api/colosseum/team/season`，领取为 `POST /api/colosseum/team/season/claim`。

## 队伍 API 速查

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/colosseum/team` | 当前账号的 4v4 队伍或 `null` |
| PUT/POST | `/api/colosseum/team` | 保存 `{members:[{heroId,position}×4]}` |
| GET | `/api/colosseum/team/opponents` | 对手幻影与服务端挑战判定 |
| POST | `/api/colosseum/team/challenge` | 发起 `{opponentTeamId}`，立即返回战报 |
| GET | `/api/colosseum/team/leaderboard` | 队伍总榜 |
| GET | `/api/colosseum/team/history` | 队伍历史战报 |
| GET | `/api/colosseum/team/season` | 当前赛季队伍榜、个人队伍排名和待领奖励 |
| POST | `/api/colosseum/team/season/claim` | 领取未领取的队伍赛季奖励 |

所有队伍接口都要求登录；受保护请求会先结算当前账号到期的远征。

## 旧版 1v1 决斗兼容规则

旧版 `/api/colosseum/opponents`、`POST /api/colosseum/duel`、`/leaderboard` 和 `/history` 在账号尚未保存 4v4 队伍时仍可用。它们按单英雄快照、初始 1000 分和 K=32 的旧规则运行；不会产生 EP、重伤或死亡。账号保存 4v4 队伍后，通用榜单、历史和赛季入口优先返回队伍数据，旧接口仅用于兼容旧客户端。
